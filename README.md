# ONE ARCANA

*Ask. Shuffle. Pick one.*

A minimal, multilingual one-card tarot experience built with Vue 3 and JavaScript.

## Run locally

```bash
npm install
npm run dev
```

To test on a phone connected to the same Wi-Fi:

```bash
npm run dev:lan
```

Open the network URL printed by Vite on the phone. The address changes when the Mac joins a different network.

## Build

```bash
npm run build
```

The 78 Rider–Waite–Smith card scans in `public/assets/tarot/cards` are public-domain “Pam-A” scans sourced from Wikimedia Commons. See the artwork directory README for details.
