# Rider–Waite–Smith card artwork

This directory contains all 78 cards from the public-domain “Pam-A” Rider–Waite–Smith tarot deck scan set uploaded by TaionWC.

- Original artwork: Pamela Colman Smith, 1909.
- Source: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
- Copyright status: the original Rider–Waite–Smith deck is public domain in the United States and the United Kingdom. These files do not use a modern copyrighted recoloring.
- Local filenames match each card's `id` in `src/tarotData.js`, such as `the-fool.jpg`, `wands-ace.jpg`, and `pentacles-ten.jpg`.

The page retains its editorial fallback artwork in case an individual image ever fails to load.
